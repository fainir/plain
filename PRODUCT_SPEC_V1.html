📍 URL Structure & Pages

/
Home page - Browse planner types (unauthenticated) OR Workspace list (authenticated)
/login
Authentication page - Sign in / Sign up
/life
Life planner landing page with integrated chat
/food
Food planner landing page with integrated chat
/fitness
Fitness planner landing page with integrated chat
/finance
Finance planner landing page with integrated chat
/p/:workspaceId
Workspace view with sidebar, tables, views, and chat
/p/:workspaceId/:docId
Specific table or view within workspace (e.g., /p/abc123/today, /p/abc123/goals)
Key Design Principles:
• No separate /planners route - planner types shown directly on home for unauthenticated users
• No separate /chat route - chat is integrated into planner pages and workspaces
• Authenticated users see workspace list at / (root)
• Short /p/ prefix for workspace URLs (clean and memorable)
• Direct doc/view URLs allow deep linking and bookmarking

⚡ Core Capabilities - Version 1.0

1. AI-Powered Plan Generation

Natural Language Input Chat interface accepts plain English requests for any type of plan
Smart Workspace Routing AI determines whether to add to existing workspace or create new one
Category-Based Organization Plans organized by categories (Health, Finance, etc.) within workspaces
Pre-populated Data Generated plans include realistic goals, actions, and timelines
View Generation AI creates relevant views (Today, This Week, Kanban, etc.) based on plan type
Continuous Refinement User can chat to modify, add, or remove elements from generated plans

2. Flexible Data Management

Universal Tables Core tables (Goals, Actions, etc.) work across all plan types
Custom Tables Add plan-specific tables (Meals, Workouts, Budget, etc.) via chat or manually
Manual Data Entry Users can add, edit, delete rows in any table
AI Data Modification Chat can update existing data: "Mark marathon goal as completed"
Category Filtering Filter any view by categories to focus on specific plans
Multi-Category Views Views can show data from multiple categories or single category

3. Dynamic View System

Default Views Today, This Week, All Goals, All Actions created by default
Custom Views via Chat "Create a Kanban board for my fitness actions"
Manual View Creation Power users can create views with custom filters and layouts
Multiple Layouts Table, Kanban, Calendar, Timeline, Gallery, Chart, Hierarchy
Smart Filtering Views automatically filter by date, status, category, etc.
Direct View URLs Each view has its own URL (/p/:workspaceId/:viewId) for bookmarking

4. Workspace Management

Multiple Workspaces Separate workspaces for different contexts (Life, Work, etc.)
Default Workspace First plan creates Life Planner workspace automatically
Empty Workspace Creation Create blank workspace with default structure from home page
Smart Icons Workspaces have customizable emoji icons
Easy Switching Switch between workspaces via home page (/) or sidebar
Workspace Sorting Life Planner always appears first in list

5. Authentication & User Management

Email/Password Auth Simple sign up/sign in with Supabase
Guest Plan Generation Generate plans before auth, prompt to save
Post-Auth Redirect Return to generated plan after authentication
Session Persistence Stay logged in across sessions
User-Scoped Data Each user sees only their workspaces via RLS
Home Page Intelligence Show workspace list if authenticated, planner types if not

6. Chat-Driven Interface

Integrated Chat Chat embedded in planner pages and workspaces, no separate route
Context Awareness Chat knows current workspace and can reference existing data
Multi-Step Operations "Add weekly date nights and link to relationships goal"
Data Modification Chat can create, update, delete any data
Schema Modification Chat can add tables, views, categories
Suggestions AI suggests improvements: "Want to add a habit tracker?"

🔧 Technical Foundation

Database Schema

  • workspaces: User workspaces with name, icon, description
  • workspace_members: User access to workspaces (RLS enabled)
  • categories: Hierarchical categories within workspaces
  • table_schemas: Table definitions (Goals, Actions, etc.)
  • view_schemas: View configurations (filters, layouts, columns)
  • table_data: Actual data rows with JSONB storage

Core Tables (Default in Every Workspace)

  • Goals: High-level objectives with target dates, progress tracking
  • Actions: Tasks and todos linked to goals, with scheduling
  • Resources: Links, files, notes related to goals/actions
  • Milestones: Key checkpoints in goal achievement
  • Reflections: Journal entries and progress notes

Default Views

  • Today: Actions due today or overdue (/p/:id/today)
  • This Week: Actions for current week (/p/:id/this-week)
  • All Goals: Table view of all goals (/p/:id/all-goals)
  • Active Actions: All incomplete actions (/p/:id/active-actions)
  • Calendar: Timeline view of dated items (/p/:id/calendar)
  • Progress Dashboard: Chart view of goal completion (/p/:id/progress)

Default Categories

  • 💪 Health & Fitness (with subcategories: Nutrition, Exercise)
  • 💰 Finance
  • ❤️ Relationships
  • 🌱 Personal Growth
  • 💼 Career
  • 🏠 Home & Living
